# 在本地跑起来（Android 模拟器）

真机验证一轮要「装 APK → 试 → 截图 → 口头描述」，一次反馈十分钟起步。
用模拟器可以直接拿 logcat、截图、甚至 `adb root` 翻应用目录，定位快一个量级。

> 硬约束：Google 的模拟器在 x86 主机上**不支持 arm64 镜像**，所以必须另编一套
> **x86_64** 的原生库。发布包仍然只带 arm64 / armeabi-v7a。

## 一次性准备

需要：Android SDK（cmdline-tools）、emulator、platform-tools、
`system-images;android-33;default;x86_64`，以及可用的硬件加速（Windows 上是 WHPX）。

```bash
# WHPX 是否可用（输出 "is installed and usable" 就行）
$SDK/emulator/emulator.exe -accel-check
```

AVD 可以手写（省掉 avdmanager 的交互）：

```ini
# %ANDROID_AVD_HOME%/kanfan.ini
avd.ini.encoding=UTF-8
path=<AVD 目录>\kanfan.avd
path.rel=avd/kanfan.avd
target=android-33
```

```ini
# kanfan.avd/config.ini（关键几项）
abi.type=x86_64
hw.cpu.arch=x86_64
image.sysdir.1=system-images/android-33/default/x86_64/
hw.gpu.mode=swiftshader_indirect
hw.ramSize=3072
```

启动：

```bash
emulator.exe -avd kanfan -no-snapshot -no-boot-anim -gpu swiftshader_indirect -no-audio
adb wait-for-device && adb shell getprop sys.boot_completed   # 等到 1
```

## 编 x86_64 原生库

四个引擎都要各编一份，产物放 `libs/<引擎>/x86_64/`：

| 组件 | 做法 |
|---|---|
| `libkanfan.so` | `bash native/build_native.sh x86_64` |
| `libjlibtorrent` | Maven 的 `jlibtorrent-android-x86_64` 包里解出来 |
| `libonscripter.so` / `libsdl.so` | ONS 源码 CMake 换 `-DANDROID_ABI=x86_64` |
| `libmain.so` / `libSDL2.so` | krkrsdl2 + SDL2 + ffmpeg 全部换 x86_64 重编 |

ffmpeg 也要一份 x86_64 的静态库（`--arch=x86_64 --cc=x86_64-linux-android21-clang`），
然后 `cmake -DFFMPEG_ROOT=<x86_64 前缀>`。

## 出测试包

`build.sh` 支持只打指定 ABI：

```bash
ANDROID_SDK_ROOT=$SDK KANFAN_ABIS=x86_64 bash build.sh
```

产物还是 `out/kanfan.apk`，只含 `lib/x86_64/`，约 15 MB。

## 装 + 跑 + 抓日志

```bash
adb install -r out/kanfan.apk

# 片库有个调试入口，可以跳过 SAF 直接进引擎：
adb shell am start -n com.kanfan.player/.MainActivity \
  --es krkr /data/data/com.kanfan.player/files/games/test

adb logcat -c && adb logcat | grep -E "SDL/APP|libc|FORTIFY"
adb exec-out screencap -p > shot.png
```

**原生日志**比 logcat 更好用：引擎自己会往
`/sdcard/Android/data/com.kanfan.player/files/diag/krkr-native.log` 写打点，
崩溃时还会记信号 + 栈帧偏移（用未 strip 的 `.so` + `llvm-addr2line` 还原）。

```bash
adb shell cat /sdcard/Android/data/com.kanfan.player/files/diag/krkr-native.log
```

## 往模拟器里放游戏

`/sdcard/Android/data/<包名>/` 走 FUSE，`adb push` 会被拒（"Is a directory"）。
先中转再复制：

```bash
adb push . /data/local/tmp/game
adb shell mkdir -p /data/data/com.kanfan.player/files/games/test
adb shell "cp -r /data/local/tmp/game/. /data/data/com.kanfan.player/files/games/test/"
adb shell "chown -R u0_a126:u0_a126 /data/data/com.kanfan.player/files/games/test"
```

`adb root` 在模拟器上可用，复制/看文件都方便；真机不行。

## 已知坑

- **MSYS 会改写 `/sdcard/...`**：Git Bash 下所有 adb 命令都要 `export MSYS_NO_PATHCONV=1`，
  本地路径则写 `D:/tmp/xxx`。
- **`run-as` 需要 debuggable**：正式包不行，别指望它。
- **`-no-window` 下 GLES 可能白屏**：要截图就带窗口。
- **arm64 镜像跑不了**：x86 主机上只能用 x86_64 镜像，所以必须有 x86_64 的原生库。
